# uCRM-9 Airfoil Profile Data

This directory contains 21 airfoil profile coordinate files from the Taylor-Hunsaker dataset, covering spanwise locations from 0% to 100% semispan of the uCRM-9 wing.

## Files Included
- `uCRM-9_wr0_profile.txt` through `uCRM-9_wr100_profile.txt`
- Each file contains x,y coordinates normalized by local chord length
