# uCRM-9 Model Files

This directory contains two files from the uCRM-9 dataset:
- `uCRM-9_aero_forces_1.0g_coarse.bdf` - Aerodynamic forces data
- `uCRM-9_wingbox_coarse.bdf` - Wingbox structural model

## Data Source and Attribution

**Original Dataset**: [uCRM: undeflected Common Research Model](https://data.mendeley.com/datasets/gpk4zn73xn/1)

**Citation**: Brooks TR, Kenway GKW, Martins JRRA. Benchmark Aerostructural Models for the Study of Transonic Aircraft Wings. AIAA Journal. 2018;56(7):2840-2855.

**Usage**: These files are used under academic fair use for research purposes. The complete dataset contains additional files and documentation available at the Mendeley Data repository.
